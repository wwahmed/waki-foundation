# waki-ai-service on cdn.wakilabs.dev

Anonymous publishing point for the WakiAIService release artifacts.
Lets the truly anonymous `curl | bash` install path work without
needing the user to authenticate against the private GitHub repo.

## What lives here

- `latest.json`  -> version manifest the running .app polls via
  `/api/update-check`. Generated by the WakiAIService release
  workflow (see `~/workspaces/WakiAIService/.github/workflows/release.yml`)
  and copied here by the maintainer step
  `bash ~/workspaces/WakiAIService/scripts/publish-latest-json.sh`.
- `install.sh`   -> anonymous one-liner installer. Pulls `latest.json`,
  downloads the matching `.dmg` from this same CDN folder,
  verifies sha256, copies to /Applications, registers Login Items,
  launches.
- `uninstall.sh` -> mirror of WakiAIService/scripts/uninstall.sh.
- `WakiAIService-X.Y.Z.dmg` + `.sha256` -> the per-release
  artifacts. Mirrored from GitHub Releases by the publish step.

## Anonymous install path

```bash
curl -fsSL https://cdn.wakilabs.dev/waki-ai-service/install.sh | bash
```

No `gh auth login` needed; the WakiAIService GitHub repo can stay
private.

## Publishing flow

After tagging a new release in `wwahmed/WakiAIService`:

```bash
cd ~/workspaces/WakiAIService
bash scripts/publish-latest-json.sh   # downloads release artifacts
                                       # into wakilabs-cdn/waki-ai-service/

cd ~/workspaces/wakilabs-cdn
wrangler pages deploy . --project-name=wakilabs-cdn --branch=main \
  --commit-dirty=true
```

That deploy step is the one currently waiting on the CLI worker
session that owns the wakilabs.dev zone (because the Pages
project's custom domain binding is still pending).
